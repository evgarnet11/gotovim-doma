# Готовим дома

135 рецептов для аэрогриля, уникальные иллюстрации, поиск, таймеры и кабинет автора.

GitHub Pages: публикуется из корня ветки main. Общие рецепты сохраняются на сервере https://vkusno-doma-airfryer.evgeniia077.chatgpt.site . Пароля в кабинете автора нет, как предусмотрено семейным сценарием приложения.

Фотографии включены в index.html; это позволяет загрузить приложение одним небольшим набором файлов. В комплекте есть рецептная база для офлайн-просмотра. Общие изменения сохраняются при наличии интернета. Избранное и таймеры принадлежат текущему устройству.

Android: меню браузера → Установить приложение. iPhone: Safari → Поделиться → На экран Домой. Иконка — логотип на светлом яичном фоне.
